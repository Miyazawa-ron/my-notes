## 二、表格列说明（数据字段）

每个分类文件中的表格均为以下 8 列，顺序固定：

| 列名 | 字段含义 | 说明 |
|---|---|---|
| `#` | 序号 | 文件内部序号 |
| `单词` | 日语写法 | 含汉字者写汉字，纯假名词写假名 |
| `假名` | 假名读音 | 汉字词的读法（振假名） |
| `罗马音` | 罗马字注音 | **键盘输入式（wapuro）罗马音**，与假名一一对应，便于打字与记忆假名 |
| `词性` | 词类 | 名 / 动1 / 动2 / 动3 / い形 / な形 / 副 / 疑 / 连 / 助 等 |
| `中文释义` | 中文意思 | |
| `例句` | 日文例句 | N5 难度短句 |
| `例句中文` | 例句翻译 | |

### 词性缩写对照

- **名** = 名词
- **动1** = 五段动词（一类动词）
- **动2** = 一段动词（二类动词）
- **动3** = サ変/カ变（三类动词，如 する・来る）
- **い形** = い形容词
- **な形** = な形容词（形容动词）
- **副** = 副词
- **疑** = 疑问词
- **连** = 连词 / 接续词
- **指** = 指示词（这/那等）
- **助** = 助词
- **数** = 数词 / 量词
- **感** = 感叹词 / 寒暄语

### 罗马音规则（重要）

本表采用**键盘输入式罗马音**（与假名一一对应），而非 Hepburn 标准式，原因是更利于 ① 记假名 ② 用日语输入法打字：

- し→shi　ち→chi　つ→tsu　ふ→fu　じ→ji
- 长音按假名写出：おう→ou（如 おはよう=ohayou）、すう→suu
- 促音「っ」用双辅音：きって→kitte
- 拨音「ん」→n（がっこう=gakkou，しんぶん=shinbun）

## 三、后期开发应用建议

1. **解析方式**：每个 `.md` 文件的表格行可逐行 split `|`，得到 8 个字段，直接转 JSON 对象。
2. **建议 JSON 结构**：

```json
{
  "id": "01-001",
  "word": "おはよう",
  "kana": "おはよう",
  "romaji": "ohayou",
  "pos": "感",
  "meaning_zh": "早上好",
  "example": "おはようございます。",
  "example_zh": "早上好。",
  "category": "寒暄与基础表达"
}
```

3. `id` 可用 `文件编号-行号` 生成全局唯一键。
4. 背单词应用可按 `category` 分组、按 `pos` 筛选、用 `kana` 做听写、用 `romaji` 做输入练习。
